# Nodes

| Node | What it does | Guide |
|---|---|---|
| UPAI Model | Defines one model, its kind, price, limits and reference labels. | [upai-model.md](upai-model.md) |
| UPAI Limits | Lowers reference counts and duration or count ranges. | [upai-limits.md](upai-limits.md) |
| UPAI Prompt | Carries the prompt and optional negative prompt. | [upai-prompt.md](upai-prompt.md) |
| UPAI Image Ref | One image reference input. | [upai-image-ref.md](upai-image-ref.md) |
| UPAI Video Ref | One video reference input. | [upai-video-ref.md](upai-video-ref.md) |
| UPAI Audio Ref | One audio reference input. | [upai-audio-ref.md](upai-audio-ref.md) |
| UPAI Start Frame | Optional start frame for video models. | [upai-start-frame.md](upai-start-frame.md) |
| UPAI End Frame | Optional end frame for video models. | [upai-end-frame.md](upai-end-frame.md) |
| UPAI Settings | Sizes, resolution labels, duration, frame rule and count. | [upai-settings.md](upai-settings.md) |
| UPAI Output | Writes results and registers them with the pack. | [upai-output.md](upai-output.md) |
